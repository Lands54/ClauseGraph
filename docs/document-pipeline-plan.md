# 文档处理、条款树和总图验收计划

负责人为 `document_graph`。现行对照固定在 `9445754`。本轮完成基线探针和验收设计，候选后端尚未安装或实测。

## 实施顺序

1. 先为 PDF 做可选的本地 Docling 适配器，从结构化结果获取阅读顺序、标题候选、表格和原页坐标。文本页优先使用已有文本层。扫描页和混合页用配置明确的中文 OCR，记录实际采用的引擎、模型版本与复核信息。用同一批样本对照 PaddleOCR PP-StructureV3。MinerU 留作复杂版面对照。
2. 由 ClauseGraph 负责恢复条款层级。DOCX 继续使用原生大纲及样式；遇到缺失标记时，结合编号、相邻章节、版式等信息补判。PDF 使用书签、编号和版面块。单独处理目录、页眉页脚、需求编号列表及附录内重复编号；无把握时记录诊断。标题、正文、表格各自保留来源，不经过 Markdown 中转。
3. 保存输入原件哈希及能区分同页不同块的位置，保留旧 DOCX/Markdown 位置。解析后端及有效配置纳入版本指纹。覆盖 CLI、SDK、批处理和工作台，扫描失败时带页码报错并保持原活动版本。
4. 用相同的公共条款身份和来源位置串联三路结果。复用现有融合与发布流程，校验每条断言和证据可回查。GJB 历史树可用于辅助标注；若提供转换入口，保留历史扫描与衍生 PDF 的各自哈希。

候选来源为 [Docling 结构化文档](https://docling-project.github.io/docling/concepts/docling_document/)、[PaddleOCR PP-StructureV3](https://www.paddleocr.ai/main/en/version3.x/pipeline_usage/PP-StructureV3.html)及 [MinerU](https://github.com/opendatalab/MinerU)。固定版本时同时记录代码与模型许可；[MinerU 当前仓库许可](https://github.com/opendatalab/MinerU/blob/master/LICENSE.md)含附加条件。

## 基线和验收

下表数值是实施前的建议验收线。先冻结样本、标注、评分脚本和运行配置，再跑对照。后端选型使用开发样本，验收使用按项目或文档分隔的留出样本，文本版与扫描版的同源页划到同一组。答案文件和历史 OCR 输出只用于人工核对，不作为解析输入。

| 测试 | 数据与做法 | 通过条件 |
| --- | --- | --- |
| DOCX 兼容与标题恢复 | 跑现有 245 份 DOCX。对星网需求文档删除 44 处标题样式引用，保留正文、顺序与表格。另造编号列表、目录和带编号表格作为负例。 | 原件 245/245 可导入；现有显式标题的树及证据兼容。去样式副本成功导入，和原件的人工确认结构相比，标题及父子边 F1 均 ≥95%；负例不得形成条款。 |
| PDF 条款层级 | 人工复核 GJB 页样本，覆盖目录、正文、多个附录同号条款、跨页表格与页眉页脚。用同一页构造保留文本层、仅图像和混合版。另设仅文本提取加编号规则的朴素 PDF 对照。 | 三种输入均可导入；按标题和页块对齐后分别报告标题 F1 与父子边 F1，父子边 F1 ≥90%，比朴素对照至少高 5 个百分点，或达到 ≥98%。目录、页眉页脚不得入树。 |
| OCR 与表格 | 同批扫描页对照 Docling 的中文 OCR 与 PP-StructureV3；按正文、条号、表格分别评分。按人工转录计算 CER（编辑距离 ÷ 标注字符数）；按行列坐标和内容计算表格单元格 F1。 | 常规清晰中文扫描页 CER ≤5%，关键条号与需求编号全部匹配，表格单元格 F1 ≥90%。单列旋转、低清晰度和跨页表格结果。记录耗时、峰值内存、实际 OCR 页数。 |
| 证据与图融合 | 用 PDF 同页两个独立命中块、表格单元格和星网 10 处预置错误的文档位置。给相同条款树与确定性三路输入生成总图。 | 两个同页块均保留且可回查；10/10 文档锚点可定位。按原有语义去重并保留各路断言，无悬空边。重复构建的规范化图一致，有 Neo4j 时验证重复发布。 |
| 错误和入口一致性 | 用同一原件测试 SDK、CLI、批处理和 Web；覆盖损坏、加密、OCR 缺依赖及中途失败，并测试替换已有活动版本。 | 相同配置的条款树一致；错误可定位到文件，涉及页面时可定位到页；原活动版本和已有快照可用。 |

基线实测为 GJB 案例 200/200、企业合册 40/40、星网 5/5。星网 `01_` 原件可识别 44 个非根条款。用 ZIP 工具仅删除 `word/document.xml` 中值为 `Heading1` 至 `Heading9` 的 `w:pStyle` 自闭合标签后，现有解析器报“文档没有可识别的标题”。现有引擎对 PDF 的结果记为不支持，不能把它用作 OCR 字符错误率对照。星网预置错误表只用于验证证据定位，不能证明自动合规判定正确。
