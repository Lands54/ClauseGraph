# ClauseGraph 项目文档

ClauseGraph 把结构化文档转换为可回查原文的图谱。它保留文档及条款层级，再从词项相似度、预定义本体和文档内容概念三个角度建立关系。项目工作台用于导入文件、管理活动版本、选择文件生成 Neo4j 快照，以及生成查询。

输入支持带显式标题的 DOCX、Markdown 和符合契约的条款树 JSON。用户指定文档 ID、可选文档类型和 Turtle 本体。单份文档可独立运行，多份文档可组成同一个检索语料。PDF、OCR、视觉标题推断和自动合规判定属于当前版本之外的范围。
